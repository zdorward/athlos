# Quality Session and Strength Day Placement

**Date:** 2026-03-17

This document records the reasoning behind scheduler decisions for tempo run placement and strength session placement within the training week.

---

## Tempo Run Placement: Wednesday, Not Tuesday

### The Common Pattern

Pfitzinger's *Advanced Marathoning* places the lactate threshold/tempo workout on **Tuesday**, and this has become the de facto standard among advanced recreational marathoners. The Pfitz 18/55, 18/70, and 12/55 plans all use Tuesday as the primary quality day.

This is not wrong. Two days of recovery after Sunday's long run is sufficient for an advanced runner to execute a quality tempo. Tuesday is a physiologically sound placement.

### Why Athlos Uses Wednesday

Athlos uses **Wednesday** for the single quality session in Base (and the primary quality session in Build/Peak). The reasons:

1. **Better strength session placement.** With a Mon–Fri running schedule and Sunday long run, Wednesday tempo creates two non-adjacent, well-spaced strength slots: Monday and Friday. Tuesday tempo leaves only Thursday + Friday as eligible strength days — and those are adjacent, so only one can be selected. Since modern evidence (PMC11052887, 2024) establishes heavy resistance training as a primary performance intervention — not supplemental — getting 2 strength sessions per week matters.

2. **Wednesday is used by elite programs.** RunnersConnect elite training schedules and several sub-3 hour marathon programs place the key midweek quality session on Wednesday. It is not unconventional at the advanced level.

3. **Three days post-long-run.** Wednesday gives one additional day of recovery after the long run compared to Tuesday. The difference is marginal for advanced runners, but the direction is correct.

### What This Is Not

The move to Wednesday is not a claim that Tuesday is "incorrect." There is no peer-reviewed evidence that Wednesday produces better tempo performance than Tuesday. The decision is structural — it produces a more physiologically sound overall week layout.

## Strength Day Placement

### Science Basis

Meta-analyses (PMC11052887, 2024; PMC9653533, 2022) establish that heavy resistance training (≥80% 1RM) meaningfully improves running economy (ES = −0.426 combined with plyometrics, ES = −0.266 heavy load alone). This is one of the most replicated findings in modern running performance research. The prescription is **2x/week** in Base and Build.

### Placement Rules

Strength sessions are placed on easy run days, subject to these constraints:

1. **Not the day before the long run.** Strength immediately before the long run risks compromised long run quality and injury. The day *after* the long run (Monday) is acceptable — the concern is pre-effort fatigue, not post-effort recovery.

2. **Not adjacent to quality sessions (either side).** Doing strength the day before a tempo or interval session impairs quality. Doing it the day after means recovering from two hard efforts simultaneously. Both directions are blocked.

3. **Two strength days must not be adjacent to each other.** Minimum 48 hours between resistance sessions for adequate neuromuscular recovery.

### Why "Pre-Only" for Long Run Adjacency

The original scheduler used symmetric adjacency for the long run — blocking both the day before (Saturday) and the day after (Monday). Modern coaching practice commonly places an easy run + strength session on Monday as a recovery-day activation strategy. The physiological rationale for blocking Monday is weak: Sunday's long run is already done; Monday strength does not increase injury risk or impair any upcoming effort.

Changing to pre-only (block Saturday, allow Monday) is consistent with how coaches at the elite level structure recovery weeks — the concern is always about arriving at the hard effort fresh, not about what happens after it.

### Resulting Week Structure (Mon–Fri + Sun long run)

| Day | Base | Build early | Build late | Peak |
|-----|------|-------------|------------|------|
| Mon | Easy + Strength | Easy + Strength | Easy + Strength | Easy + Strength |
| Tue | Easy | Easy | Easy | Easy |
| Wed | Tempo | Tempo | Tempo | MP |
| Thu | Easy | Easy | Easy | Easy |
| Fri | Easy + Strength | Intervals + Strength | MP + Strength | Tempo |
| Sat | Rest | Rest | Rest | Rest |
| Sun | Long | Long | Progression | Progression |

This layout gives:
- 2 non-adjacent strength sessions in Base and Build (Mon + Fri)
- Quality sessions maximally spaced from the long run and from each other
- No hard effort preceded by strength on the prior day
